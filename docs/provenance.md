# 来源与服务器版说明

本项目的前身是「虾大助手」Android 应用。服务器版参考用户提供的 APK 进行静态分析，核对学校平台的登录流程、签到接口和历史查询行为，再实现独立的 Python 服务与网页界面。

## 参考包

- 应用名称：虾大助手
- Android 包名：`com.xmu.assistant`
- 版本：`1.7.4`（versionCode `31`）
- APK SHA-256：`C388FFF7B41BBF29C04FC9D787152BDF787A60BB52CA221BDE4D0F5CD7DF14E6`

APK 的部分混淆方法不能完整反编译。已读取的关键登录、签到和历史查询代码用于确认协议；静态代码证据与服务器实测结果分别记录，不能据此保证平台今后一直兼容。

## 本仓库提供的服务器实现

- Python / FastAPI 后台，通过学校 HTTPS 接口访问本人课程和考勤。
- SQLite 保存本人记录与操作状态，凭据使用 Fernet 加密保存。
- 中文网页按学期查看课程，本学期默认展开，其他学期折叠。
- 数字与雷达签到可独立配置，默认等待其他 10 名已到同学后处理。
- Ubuntu `systemd` 配置，支持常驻运行、开机自启和异常重启。
- Docker 备用配置及使用合成数据的自动化测试。

发布内容包含当前服务器版的源码、测试和部署配置。原 APK、反编译输出、账号密码、Cookie、数据库、密钥及真实考勤数据均保留在各自使用环境，不纳入仓库。

项目不是厦门大学官方应用；应用名称、平台名称和接口地址仅用于说明兼容对象。此来源记录不代表原 APK 作者参与或认可当前服务器版。
